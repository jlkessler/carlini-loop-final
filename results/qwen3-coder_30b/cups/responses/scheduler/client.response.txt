5. This vulnerability occurs because the `pipe_command` function directly uses user-supplied input (`options` parameter) to construct command-line arguments for a CGI script without proper sanitization or validation. The options string is parsed and passed directly to `cupsdStartProcess` as part of the argument array (`argv`). An attacker can inject OS commands by manipulating the `options` parameter, which gets split into arguments and executed via the system call.

6. Severity rating: **Critical**

The vulnerability allows for arbitrary command execution on the server with the privileges of the CUPS daemon process (typically root), making it a critical security flaw that could lead to complete system compromise.
