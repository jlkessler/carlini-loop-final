1. File: scheduler\subscriptions.c
2. Name of the function containing the vulnerability: `cupsd_start_notifier`
3. Vulnerability type / CWE: Command Injection / CWE-78
4. The relevant vulnerable code snippet:

5. A concise explanation of why it is vulnerable:
The function `cupsd_start_notifier` extracts the "scheme" from the `sub->recipient` URI (the part before the first colon). This `scheme` string is then concatenated into a file path used by `cupsdStartProcess`. If an attacker can control the `recipient` URI (e.g., via a subscription request), they can provide a scheme containing path traversal characters (like `../`) to execute arbitrary binaries located elsewhere on the system, instead of the intended notifiers in the `/notifier/` directory. For example, if `sub->recipient` is set to `../../bin/sh:something`, the resulting `command` becomes `[ServerBin]/notifier/../../bin/sh`, leading to arbitrary command execution.
6. Severity rating: Critical
